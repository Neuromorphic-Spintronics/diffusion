% or, in compact vector notation, $\mathrm{d}\mathbf{x} = \mathbf{f}(\mathbf{x}, t)\,\mathrm{d}t + \mathbf{G}(\mathbf{x}, t)\,\mathrm{d}\mathbf{W}$, where $\mathbf{f} = (f_1, \ldots, f_m)^\top\colon \mathbb{R}^m \times \mathbb{R} \to \mathbb{R}^m$ encodes the deterministic drift (comprising restoring forces, damping, external driving, and inter-component coupling), $\mathbf{G}\colon \mathbb{R}^m \times \mathbb{R} \to \mathbb{R}^{m \times p}$ is the diffusion matrix specifying how $p$ independent Wiener processes $\mathbf{W}(t) \in \mathbb{R}^p$ enter the dynamics, and the system is subject to initial conditions $\mathbf{x}(0) = \mathbf{x}_0$.  Each noise term $\mathrm{d}W_j$ may be white or coloured; coloured noise is generated by augmenting the state vector with an auxiliary Ornstein--Uhlenbeck process (e.g., see \S\,\ref{ssec:duffing}).  When $\mathbf{G} = \mathbf{0}$ the problem reduces to a deterministic initial value problem; when $\mathbf{G}$ is state-independent the noise is additive; and when $\mathbf{G}$ depends on $\mathbf{x}$ the noise is multiplicative.  In the simulated examples considered here, the noise is additive and state-independent.

Each trajectory is a discretised vector representation of a continuous function $q^{(i)}(t)$ over the temporal domain $\mathbf{t} = (t_1, t_2, \ldots, t_n, \ldots, t_{N_T})$:

% where each element $q^{(i)}_n \approx q^{(i)}(n\,\Delta t)$ is a discrete approximation to the continuous trajectory at time $t_n = n\,\Delta t$, with $\Delta t = T / N_T$ the time step and $T$ the total integration time.  We set $t_1 = 0$ without loss of generality.  These trajectories, together with any associated conditioning information (initial conditions, system parameters, or driving protocols), constitute the training data from which the diffusion model learns the distribution over dynamical trajectories.
